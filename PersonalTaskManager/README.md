# Overview

Personal Task Manager is a mobile application that helps users organize and keep track of their daily tasks. Users can add a task with a title and description, view their tasks, open a task to see its details, mark tasks as completed or incomplete, and delete tasks.

The app is designed to be simple and easy to use. To add a task, the user enters a task title and description and selects "Add Task." The task then appears under "My Tasks." Users can select a task to open the Task Details page, where they can view the description, mark the task as completed or incomplete, or delete the task.

I created this application to improve my skills in mobile application development, C#, .NET MAUI, user interface design, navigation between pages, and local data storage. I also wanted to gain more experience building an application that saves user data so that it remains available when the application is closed and reopened.

# Development Environment

I developed this application using Visual Studio Code and the .NET CLI. I used my physical Android phone to run and test the application.

The application was developed using C# and .NET MAUI. XAML was used to create the user interface. The application uses .NET MAUI navigation to move between the main task list and the task details page.

The application uses local device storage to save the user's tasks and their completed status so that the information remains available after the application is closed and reopened.
