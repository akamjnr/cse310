# Overview

This software is an Expense Tracker web application built with C# and ASP.NET Core Razor Pages. The application allows users to add, view, edit, and delete personal expenses. Each expense includes an amount, category, description, and date.

The application uses a local SQLite database to store the expense information. Users can interact with the application through the web pages, and the information displayed on the Expense List page is generated from the saved data.

The purpose of creating this software is to learn how to build a web application using ASP.NET Core, work with Razor Pages, process user input, and connect a web application to a database.

# Development Environment

I developed this software using Visual Studio Code and the .NET SDK.

The programming language used for this software is C#.

The web application was created using ASP.NET Core Razor Pages.

Entity Framework Core was used to work with the SQLite database that stores the expense information.

The application runs locally using the ASP.NET Core development server.
