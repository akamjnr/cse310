# Overview

This software is a simple C# console application that displays "Hello, World!" on the screen.

The purpose of creating this software is to practise using C# and become familiar with writing, running, and publishing a simple program.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I developed this software using Visual Studio Code and the .NET SDK.

The programming language used for this software is C#.
